# Amazon EC2 Web Server Deployment

## Project Overview

This project demonstrates the deployment of a web server using Amazon EC2.

The project was completed as part of my AWS re/Start hands-on cloud learning.

## AWS Services Used

- Amazon EC2
- Amazon VPC
- Amazon EBS
- Security Groups
- Amazon Linux

## Project Objectives

- Launch an Amazon Linux EC2 instance
- Configure networking
- Configure security group rules
- Deploy a web server
- Access the web application through a browser
- Test the deployed server
- Troubleshoot common connectivity issues
